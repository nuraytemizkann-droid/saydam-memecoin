# SAYDAM visual identity

## Core idea

SAYDAM means “transparent.” The brand character is a glass frog: visible inside, slightly strange, observant and calm while everyone else shouts.

## Voice

- concise, dry and proof-first;
- funny without pretending risk is harmless;
- confident about verifiable facts, modest about outcomes;
- uses “show the receipt” and “verify the frog” as recurring language;
- never uses moon, rocket or guaranteed-profit clichés.

## Visual system

- Ink: `#101411`
- Paper: `#F4F5EF`
- Proof lime: `#B7FF3C`
- Glass cyan: `#70E8D1`
- Alert orange: `#FF9867`
- Receipt yellow: `#F7D94C`

Headlines use heavy grotesque styling; technical labels use monospaced text. Grids, scan lines, specimen labels and transparent surfaces reinforce “inspectable.” Use the supplied `public/logo.svg` and `public/favicon.svg`. Do not place the logo over busy imagery or add glow-heavy “crypto” effects.

## Content motifs

1. **Receipt posts:** one claim, one transaction link, one plain-English explanation.
2. **Frog checks:** the character inspects a common crypto red flag.
3. **Glasshouse updates:** weekly treasury, moderation and build notes.
4. **Corrections:** orange cards that stay visible and link to the original claim.
